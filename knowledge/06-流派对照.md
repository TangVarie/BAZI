# 06 流派对照 —— 九派体系、独门技法与矛盾取舍

## 一、谱系总览（河之洲《谈谈盲派》框架＋本库补充）

盲派远源托名鬼谷子、东方朔、徐子平；近代实分五支：
1. **神煞派**（苏国圣《盲派命理真宝》）：核心是**串宫压运**（四柱定格、十二神排宫）——金口诀资料属此系。
2. **纳音派**（小易子《盲派推命——掌经》）：正五行与纳音交错论命——刘军问答、钩玄中的纳音断性格/大运属此系。
3. **民间派**：以财官论命，吸收神煞纳音精华，集理法象法技法——中原盲派、刘军、孙海义、学员笔记（盲钳子）属此系。
4. **自创派**（段建业据郝金阳批断＋邢铭芬辑夏仲奇《命术轶闻》总结）：宾主体用做功体系——今日「盲派」主流；清娟、素水、李元森、刘恒、飞宫皆由此衍化各有侧重。
5. **简易派**（陈朝阳牛鼻子/拉车理论）：大道至简一线牵。

## 三、各派独门绝技（务必单独掌握）

### 段氏（主流骨架）
做功/效率/贼捕神、正反局、虚实应期、带象换象、连体、过河拆桥、水中捞月、冲七类、大运体用（干用支体）。

### 郝金阳遗法
- **原身入宫定六亲**（某支头顶之干为另一支原身→其象化入该宫，貂蝉式定夫）；
- 阳日主正财父偏财公公、阴日主反之；
- **忌神层层制，制一次升一次官发一次财（几何递增）**；
- 官杀「制化得力为官贵、不力为技艺、无制化为官匪病灾」三段论；
- 处女断（财星长生入主位）、阳萎断（逢合则软逢冲则硬）、强暴断（禄被杀冲）、吸毒断（木食伤空亡）、参军断（官杀墓戌/刃库）、出国断（时柱马星逢刑冲，马星按盲派四组互查）；
- 八字＝演戏（剧本场次道具论）。

### 清娟派
- **天干五合换象**（合化产物取象断行业）＋搅局星；
- **十神暗引**：食伤旺暗引比劫（贵人缘）、印枭旺暗引官杀（制印得权之理据）、比劫旺暗引印枭（学历技能）、官杀旺暗引财（财过河）、财旺暗引食伤——旺而完整不受刑穿方可暗引；
- **官宜化不宜制**（化官无官灾制官有官灾）、正者要化偏者要制；
- 偏印/枭印之辨（见食为枭、见比劫财为偏印）；
- **调候化解法**（穿黄衣利考、认干儿子通关、选城市应未运、找姨妈劝妻——把五行通关做成现实动作）；
- 悖格（劫财见财/干透劫财再透财）、背禄骑马、神仙佛道鬼象、巳申合效率第一。

### 素水派
- **三步法：找配置（主线格局）→看出处（谁的财官：与我宫/与月令国家的感应——吃皇粮/自己干/打工判定公式）→看力量（数量、旺衰、破损程度量化）**；
- 星宫感应论（六亲星必须与宫感应才作数）、负宫（宫中旺气透出处）；
- 家居风水与八字同步校验（物品故障反推流年）；
- 先天基数定位法（旬内配对定祖辈）、朝元羊刃、天煞孤星、斩子剑等煞的实用化；
- 财印验证法＋冬夏验证法＋宫位验证法三级断子女。

### 飞宫派（兴易）
- **飞宫找「遁去的一」**：水火为气金木为形土为载体，以全局金形或木形为真命主；主形控柱数定格局（控四柱＝顶级）；
- 形气生死论（气灭可转、形伤则亡）→车祸凶死总公式；
- 金木特性细则（庚申含杂气主金融气度、辛酉专一主法律刀兵；干寅怕午不怕巳、干卯怕巳不怕午…）；
- 定主诀窍（乙庚合男看庚女看乙…）；
- 一山二虎（金木两形俱透）格局自降，以水通关为用。

### 金口诀（肖派/神煞系）
- **串宫压运**（流年/大运/日干通支三级起太岁排十二神）＋三垣（胎元命宫身宫，刑冲穿绝论先天中晚）；
- 印生食泄两党比较定旺衰、最旺为病；
- 大运天干管五年支藏分管（支藏两物各两年半、三物按主中余分）；
- 命宫断死期（克命宫之运为难运、流年再克为死期）、九星照命；
- 女命专章（纯净度、三煞、铁扫帚、克夫克妻死律十余条）；
- 十神定位诀（十神×年月日时各有断语，50 条）。

### 中原盲派
- 时柱直断法（不排全盘先断六亲）、天干地支信息歌诀死律（三丁多恶疾…三亥孤泠泠）；
- 干支断祖坟宅环境（甲辰时宅左前有树有水…酉年蛇仙现）；
- 岁运君臣民论（太岁如君不可犯，三会逢太岁以太岁五行论）；
- 流年干主事象、支主吉凶；
- 富贵贫贱三平衡（五行流通/阴阳/寒燥）；
- 兄弟姐妹死律 30 条、江湖绝密 50 条（剖腹产、养子、双胞胎、秃顶、屠夫、演艺、祖坟在沟…）；
- 反吟伏吟断生死三原则＋胎养生死墓绝冲合断寿。

### 刘恒派
- 盲派节气歌＋十天干扎根歌＋**交运时辰**（火命清明前三天午时、土命芒种后九天辰时、金命处暑当日申时、木命大寒当日寅时、水命冬至前三天亥时——忌冲穿之人孕妇丧白同行）；
- 十干四季喜忌精细化（甲生卯月敢见申不敢见酉；秋乙喜丁火制金；冬木见壬无戊一贫如洗…）；
- 六合五分法、穿害歌诀（鼠羊一断休、白马怕青牛、金鸡与狗泪交流、兔龙犯着不合美、猪合元猴不到头、虎见蛇如刀断）；
- 反制格（五凶神制五凶神）大于正格；一格不能二用、变局大凶。

### 刘军（江湖问答系）
46 个「如何断」：出生环境、家境、迁移、性格体貌、身高（三元＋五行数计算）、巧笨、学龄、半路文凭、婚年穷富、夫妻强善、提干降级退休、存款欠款数目（甲己子午九乙庚丑未八…配五行数加减）、灾咎、刑之四类与免刑、食神骑禄、晚景寿限。神煞体系最全（三正、三奇、学堂金榜、狼籍、扫星、吞陷煞）。

### 学员笔记（盲人江湖功夫）
**盲钳子**（节气歌心算）、**流星赶月/小近前知**（六十年口诀心算万年历、定大小月与日干支——盲师不用万年历之根本）、五行断命钳（生我/我生/克我/我克/同我五段歌）、二十八宿配月。

### 黄寅技法（附于郝本之后）
扶抑从格框架下的专项：中奖、拾钱、被骗、被盗、抢劫、赌博、借钱、配偶方向（气势法）、牙齿定位（申酉辛庚分排）、肤色（用神旺白忌神旺黑、干面支身）。

## 四、矛盾点与取舍表

| 矛盾 | 两说 | 取舍建议 |
|---|---|---|
| 旺衰要不要 | 段氏弃用；清娟/金口诀/中原用 | 论富贵做功**不用**；论心理承载、合财胜任、身高胖瘦体貌**用**。两套并行不悖。 |
| 合能否解穿 | 段氏「合解不了穿」；清娟「有合遇冲越冲越紧」「辰酉合穿不动」 | 看三字位置与力量：合紧贴且力大可使穿失效（戌酉穿遇辰酉合则穿不动）；隔位弱合解不了。个案权衡。 |
| 三合局成立条件 | 段氏中神双现不合局论入墓；中原岁会以太岁五行论 | 原局从段氏；岁运参与时太岁本气优先（丑年会亥子丑作土旺论）。 |
| 子卯刑/自刑 | 段氏不用（子卯论破）；金口诀/江湖用 | 主体不用；断暗疾、迁移、无礼之性时可参江湖说。 |
| 驿马查法 | 传统只取对冲一位；郝派见三字任一皆马 | 用郝派宽口径，应验面大（出国断尤验）。 |
| 阴干羊刃 | 段氏不论；金口诀论 | 不论；阴干极旺时以「半禄/连体」处理。 |
| 神煞多寡 | 段氏仅五神煞；金口诀/刘军几十个 | 骨架只用五个；铁口直断与校验时辰时调用江湖煞（将军箭、斩子剑、天煞孤星、扫帚等命中率高者）。 |
| 谁是命主 | 传统日干；飞宫找主形 | 默认日干；日干无根无功、全局一形独旺时启用飞宫立极复核，两法同断则铁。 |
| 官星可制否 | 清娟「正官只能合化不能制」；段氏制官得官 | 统一为郝三段论：制化**得力**皆可贵（含制）；制格有官灾、化格无官灾；正星得正位（坐宫）不可制、偏星可制。 |
| 干支互克 | 主流支不克干；自合四柱例外 | 从主流；丁亥己亥辛巳癸巳支可克干，丙戌壬戌须未刑开。 |

## 五、融合心法

一个八字到手，九派是**一架望远镜的九个倍率**：
- 段氏定**格局贵贱**（做功）；
- 清娟/素水定**得失归属**（谁的、几成、何种方式）；
- 郝金阳/江湖口诀出**铁口细节**（一句话扎心处）；
- 金口诀/串宫压运扫**流年杂事**；
- 飞宫复核**生死大关**；
- 中原/刘军补**环境数目体貌**。
多法同指一处，方下断语；互相矛盾，回到做功本源。
