# 00 元引擎总纲 —— 多法加权论命引擎

> 本库的总入口与调度核心。把 `06-流派对照` 末节"九派＝望远镜九个倍率、多法同指方下断"的思想，从**盲派内部九支**扩展为**双轴多法加权引擎**：盲派做功（基座）＋子平系（格局用神／气数调候）＋神煞·六亲·象法等工具模块，各自独立出断并给置信度，元层（meta）按"多线索同指→加权升置信、分歧→按专长域裁决"聚合。
>
> **铁律不变**：论富贵层级与做功落点，盲派做功仍是权重最高的主轴；子平系不是来"取代"盲派，而是补"贵气清浊／调候温度／逐月喜忌／命例校准"等盲派薄弱层。矛盾处回到做功本源（见第五、六节）。

---

## 一、设计理念
1. **多法并断，而非单法独裁**。同一八字让各模块各自出断；不预设谁对。
2. **加权聚合，不是简单投票**。每个"问题域"有各自的"专长模块"，其判断在该域权重高。
3. **共识即增信，分歧即降信**。多个异源模块指向同一结论 → 铁断；相悖 → 标注并按专长域取舍。
4. **以命例校准权重**。`13-验证集` ＋ `_待整合` 三批共 ~143 真实命例（部分带 hit/miss）是权重的经验来源，可回测、可迭代。
5. **术语分命名空间**。"体用／宾主／势／虚实／向背／格局"等同名词在不同模块含义不同，引擎内一律带模块前缀，禁止跨模块直接套用（第七节）。

## 四、模块输入/输出契约
- **输入**：四柱干支 ＋ 性别 ＋ 大运（含起运岁）＋ 流年；可选：出生地/真太阳时（M7 排盘用）、胎元命宫（M3 星盘/三限用）。
- **输出**（每个问题域一条）：`{判断, 置信度(铁/可断/存疑), 依据线索[], 所属模块}`。
- 各模块互不通信，只把输出交给 meta 层。

## 五、聚合与取舍规则
1. **共识增信**：≥2 个异源模块对同一问题同指 → 置信升一级；≥3 源同指 → 铁断。
2. **分歧裁决**：按该问题域的专长权重表（第三节）取高权重模块结论为主，低权重作保留意见标注。
3. **取舍铁律**（承 `06` 第四节并扩展到跨轴）：
   - **旺衰/用神 vs 做功**：论富贵层级与做功落点，**回到 M1 做功**；M2/M7 的旺衰用神判语仅供"清浊品级/调候温度"，不参与富贵高低的最终定档。
   - **职业落象**：四源（M1做功被坏处／M2浊象与贵气坏处／M5干支取象／M7取象）同指则铁断；分歧时以"被刑冲克穿合的那个字之象"为准（四源共识器，见六节）。
   - **生死大关**：M1（做功穿禄＋飞宫水火两气俱灭）＋M3（吞陷/流霞/天地转/四大空亡）＋M7（死亡气数表）**三源同指**才下死断，且只点防范年份不说死（承 09 话术）。
   - **调候温度**：M7 与 11-穷通、12-滴天髓 三者本同源，冲突时以 11-穷通逐月用神表为准，M7 作实战口语注脚。
   - **神煞**：永不单断；只作 M1 做功结论的"定性/应期/生死旁证"。
   - **星盘（果老星宗）/纳音生克**：置信最低层，仅在其它模块缺位或需补充时参考，且需 `sources` 校核。

## 六、跨模块共识器（引擎"融会贯通"的核心接口）
这是双轴真正咬合处——几条**异源但结论同构**的原则，命中即大幅升置信：

1. **职业落象·四源同指**：M1"被做功/带忌处落象" ＝ M2"浊象＝职业落象／贵气被坏处落象" ＝ M5"干支类象（戌=殡仪馆/网络、申酉+火库=警察、丁庚=钢铁…）" ＝ 探运"取象定职业"。四源指同一字之象 → 职业铁断。
2. **七杀现实脸·实证校验**：M2"七杀有制与否看命主现实勇怯而非纸面制化" ＝ M1"以事象反推、多线索同指才下断" ＝ 验证库实证精神。→ 立为引擎的**现实校验原则**：纸面判断必须与已知事实对齐，相悖则降权重审。
3. **宫位现实象·共识**：M1 宫位象（年祖/月父母/日夫妻/时子女） ＝ M2"成败之位（时辰第一、年干第二）/天时地利人和（月令仕途、时辰财、自坐才干）" ＝ M4 星宫感应。三源定位同指 → 六亲/宫位事铁断。
4. **调候温度底色·三源**：M7 气数（寒暖燥湿、向阳解寒、阳干旺衰阴干环境）＝ 11-穷通逐月用神 ＝ 12-滴天髓衰旺真机。决定健康底色、性情急缓、富贵上限。
5. **应期多线·同年**：M1（禄/原身/遁藏透干/虚实/冲合穿）＋ M2（换格换令/有字应字/根元胜负）＋ M7（岁运并临/伏吟/死亡气数）＋ M3（神煞流年/串宫压运）多线索指向同一年 → 重断。

## 七、术语命名空间（防同名异义污染——整合中最易出错处）

| 术语 | 盲派(M1)义 | 子平系(M2/M7)义 |
|------|-----------|-----------------|
| **体用** | 做功语境：体＝印禄比劫(工具)，用＝财官杀(所求) | 论日为主：日主为体，六神为用（描述关系） |
| **宾主** | 做功中的主宾力量（主位/宾位字） | 宫位伦理：日为主时为宾、年君月臣 |
| **势** | 结党成势（木火一党等） | M7 近义"气数得时得位"；M2 基本不用 |
| **虚实** | 本柱有根无根的状态 | M2"向实寻虚/虚邀禄马"＝外格邀合（完全不同） |
| **向背** | （盲派少用） | 禄马向背：向官临财＝向禄、向伤＝背禄 |
| **格局** | 做功组合的类型 | 月令取格的八格十格（成败救应） |
| **用神/忌神** | 不用，代以功神/废神 | 贵物尊神（君），喜忌针对用神 |
| **旺衰** | 只论承载力，不取用 | M2取用第一要义；M7"旺衰看月令、强弱看根"双框架 |
| **飞宫** | 找真命主（金木主形，遁去的一） | M4"飞宫＝亲星巡宫、亲系交涉"（不同） |
| **三限** | （盲派用大运） | 子平：月初/日中/时末限＋胎元主15岁前 |

> 规则：引擎内引用这些词必须写成「盲派·体用」「子平·体用」等带前缀形式；模块文件内部默认本模块义。

## 八、引擎化看命流程（多法并断 pipeline）
整合 `09` 十二步 ＋ 雪衣"看命六步骤" ＋ 探运"气数次第"：

```
第0步 排盘校验（含真太阳时/夏令时、胎元命宫、神煞五件套；两时辰并列验已发生之事）
第1步 定温度底色（M7/11/12）：调候、寒暖燥湿、一行成势否、阳干阴干取用开关
第2步 定势与做功（M1）：结党、刑冲克穿合墓、功神废神、正反局 —— 富贵层级主判
第3步 定格局清浊（M2）：月令取格、向禄背禄、成败救应、贵气清浊 —— 品级与文武正偏
第4步 各工具模块并行：M5取象（职业/性情/物象）、M4六亲定位、M3神煞/星盘旁证
第5步 共识检测（六节）：职业四源、宫位三源、调候三源、应期多线是否同指
第6步 加权聚合 + 取舍（三、五节）：按问题域专长权重出主断，标注保留意见
第7步 分级出断：铁断/可断/存疑/不断；危及性命只点防范年份
第8步 开口次序（江湖话术，09第11步）：先六亲验时辰→性情体貌职业→富贵大运→所问→化解
第9步 复盘回填：命中归因哪模块、错断归因，更新验证库与权重表
```

## 九、置信度与校准
- **置信分级**：铁断（≥3源同指或主轴高权重且无反证）＞可断（专长模块＋1佐证）＞存疑（仅单模块或源间分歧）＞不断（关键信息缺/真太阳时不定）。
- **校准数据**：见 `19-命例验证库`。注意三批命例多为**讲师自述/盲断、未独立核验、含 OCR/ASR 还原**，作权重参考而非真值；探运 QQ盲断（B）有客户 hit/miss，可信度相对高，含 6 个负样本（老婆偷人/二妹年/学历/死季/博士层级/脏腑微差）专门用于"防过拟合/边界"。
- **演进**：每积累新校准案 → 回测各模块在各问题域命中率 → 微调第三节权重表。
