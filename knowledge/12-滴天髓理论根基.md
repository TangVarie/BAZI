# 12 滴天髓理论根基（任铁樵《滴天髓阐微》）

> 全本约13.6万字，逐章提炼＋衰旺/中和章原文精读。这是盲派"势、做功、调候、虚实"的**理论母体**——段建业自言"理在《滴天髓》"。本篇标明哪些是盲派概念的原始出处，及盲派把它改了什么名。

## 一、通神论纲领（与盲派对接最紧的章）

### 人道·顺悖（盲派"势/做功方向"的根）
原文：「戴天覆地人为贵，顺则吉兮凶则悖。」任氏：**顺者接续相生、悖者反克为害**。判木日（畏金）有救无救的链条最经典：地支有亥子生之✓→无则天干壬癸化之✓→无则地支寅卯通根✓→无则天干丙丁制之✓；反之透戊己、党助庚辛则"木无生理，凶可知"。
→ 盲派"做功要顺势、反局为凶"即此。四戊午、四丁未、四癸亥等纯气偏枯之造无不应验——盲派"一气成势"之源。

### 知命·辟用神之谬（盲派"功神/废神"的根）
原文：「用之为财不可劫，用之为官不可伤，用之印绶不可坏，用之食神不可夺。」任氏：**不拘财官印比食伤枭杀皆可为用**，不可执财官为重——这正是盲派废"财官用神"、立"功神"的祖训。批"财可养命、官可荣身"的俗论导致"财多身弱作富屋贫人、身衰官重作显贵"的妄断。

### 理气·进退（盲派"虚实/旺相"的根）
原文：「进而当令是谓旺，功成者退是谓休，退而无气是谓囚。」**将来者进为相、进极为旺、功成者退为休、退极为囚；相妙于旺、休甚乎囚**（旺极反退速，囚极将渐生）。喜神宜旺相、忌神宜休囚。
→ 盲派"虚为应期、旺极怕衰"皆出此。

### 配合干支·天覆地载（盲派"连体/通根/虚实"的根）
「干通根于支，支逢生扶则根坚、逢冲克则根拔；支受荫于干，干逢生扶则荫盛、逢克制则荫衰。必须天覆地载，不可偏废。」
→ 盲派"连体不可坏、坐下根不可伤"即此。

### 天干·十干体用（盲派"十干性情/调候"的根）
**「五阳从气不从势，五阴从势无情义」**——阳干（甲丙戊庚壬）刚而不畏财煞、处世不苟；阴干（乙丁己辛癸）柔而见势忘义。十干精义（盲派十干口诀之源）：
- 甲：参天脱胎要火、春不容金、秋不容土；火炽乘龙（寅午戌透丙丁需坐辰泄）、水宕骑虎（申子辰透壬癸需坐寅纳）。
- 乙：虽柔刲羊解牛（坐丑未制土）、怀丁抱丙不畏申酉、虚湿之地骑马亦忧（亥子无丙丁纵坐午难发）、藤萝系甲可秋可冬。
- 丙：猛烈欺霜侮雪，能煅庚金、逢辛反怯（合而寓和），土众成慈、水猖显节。
- 丁：柔中昭融，抱乙而孝、合壬而忠，旺不赫炎、衰不熄灭，秋冬得甲乙不畏金。
- 戊：固重中正万物司命，坐寅怕申冲、坐申怕寅冲（宜静），喜润不喜燥。
- 己：卑湿中正蓄藏，不愁木盛、不畏水狂，火少火晦、金多金光。
- 庚：带煞刚健，得水而清、得火而锐，土润则生、土干则脆，赢甲输乙。
- 辛：软弱温润而清，畏土之叠、乐水之盈，合丙化水，热喜己、寒喜丁。
- 壬：通河泄金气，刚中之德、易进难退，从火土相济。
- 癸：至弱达天津，得龙（辰）而运，不愁火土、不论庚辛，合戊见火化真。

### 地支·生方旺地库地（盲派"墓库刑冲"的根）
**「阳支动且强速达显灾祥，阴支静且专否泰每经年」「生方怕动库宜开，败地逢冲仔细推」**。生方（寅申巳亥）忌冲（两败）、旺地（子午卯酉）可冲（须看用神）、**库地（辰戌丑未）宜冲开**（"暮库逢冲则发"任氏斥为妄言，但库地确发福者另有得气）。
→ 盲派"财官临库喜刑冲、库不冲不发"即此，但盲派比任氏更彻底地肯定冲库。
冲的真机：**「旺者冲衰衰者拔，衰神冲旺旺神发」**——盲派"成势一方制弱方"之源。任氏视刑、穿（害）"非关命理，宜论生克"——此处盲派分道扬镳，盲派把穿提到了第一位。

## 二、衰旺真机（盲派"成势"的完整母体，本篇核心）

原文：**「能知衰旺之真机，其于三命之奥，思过半矣。」**

任氏破"得令为旺失令为衰"的死法，立两条铁律：
1. **「旺中有衰者存不可损，衰中有旺者存不可益；旺之极者不可损，衰之极者不可益」**——这就是盲派"顺势不可逆"。
2. **五行颠倒十法（极旺极衰反象）**——盲派"金木形论""一行得气"的直接祖本：

| 太旺（似下一行，喜泄/克其旺） | 旺极（性变，喜克其变） |
|---|---|
| 木太旺似金，喜火炼 | 木旺极似火，喜水克 |
| 火太旺似水，喜土止 | 火旺极似土，喜木克 |
| 土太旺似木，喜金克 | 土旺极似金，喜火炼 |
| 金太旺似火，喜水济 | 金旺极似水，喜土止 |
| 水太旺似土，喜木制 | 水旺极似木，喜金克 |

| 太衰（似上一行，宜生之） | 衰极（性变，宜生其变） |
|---|---|
| 木太衰似水，宜金生 | 木衰极似土，宜火生 |
| 火太衰似木，宜水生 | 火衰极似金，宜土生 |
| 土太衰似火，宜木生 | 土衰极似水，宜金生 |
| 金太衰似土，宜火生 | 金衰极似木，宜水生 |
| 水太衰似金，宜土生 | 水衰极似火，宜木生 |

任氏以二十造逐一验证（如壬辰壬寅甲寅庚午：木太旺似金，弃庚不用、用午火泄，火运发财十余万；癸酉甲子癸亥辛酉：水冲奔顺其流为美，逆水之运刑妻克子）。
> **盲派转译**：段氏"成势→顺势做功"、飞宫"金木为形顺其生死"、清娟"势与日主一致"，全部是这一章的口语化、可操作化。盲派把"旺极宜泄不宜克"细化成"制净/制不净/反局"的判级体系。

## 三、中和、源流、通关（"做功/通关"的根）

- **中和**：「有病方为贵，无伤不是奇；格中如去病，财禄两相宜」。任氏：中和为正理（无病之人），偏气虽不中和但纯正者"恩怨分明、岁运补不足则后发"。→ 盲派"制病得用、制去忌神得忌神喜"之源。
- **源流**：「何处起根源，流到何方住」——源头＝局中旺神，流住之地＝喜神归宿，阻节之神定吉凶六亲。→ 盲派"找势的源头与归宿、看中间被谁挡"即此。
- **通关**：「关内织女关外牛郎，此关若通相邀入洞户」「木土要火、火金要土、土水要金、金木要水」。通关六法（自然通、岁运暗冲暗会通、官化、比劫解、冲开、克去间神）。**→ 这就是盲派"做功"的静态母体；盲派把"通关"从原局分析扩展为岁运动态激活，系统化为做功体系。**

## 四、官杀、伤官、清浊、真假（盲派分科与虚实的根）

- **官杀去留舒配**：「官杀混杂来问我，有可有不可」「杀即官也，同流共派可混；官非杀也，各立门墙不可混」。六格：财滋弱杀、杀重用印、食神制杀、合官留杀、官杀混杂（坐旺印则通）、制杀太过（再行制运九死一生）。日主旺可混、休囚不可混。→ 盲派"官杀混杂行官杀运不吉""制杀太过反凶"之源。
- **伤官见官**：「伤官见官果难辨，可见不可见」。可见官三式（身弱伤旺见印、身旺伤旺见财、伤旺财轻有比劫）；伤官五格（用印/财/劫/伤/官）＋假伤官。→ 盲派"伤官配印贵、伤官见官祸、伤官当财"全套之源。
- **清浊**：「一清到底有精神，澄浊求清」「满盘浊气令人苦」。→ 盲派"做功效率/制净"的品相维度。
- **真假神**：「真假参差难辨论，提纲不与真神照，暗处寻真也有真」。真神失势假神得局则以假作真。→ **盲派"虚实/换象/反客为主"的理论根**：看似有用的虚、看似无用的实。

## 五、寒暖燥湿、刚柔、从化（调候与从格的根）

- **寒暖燥湿**：「天道有寒暖、地道有燥湿」——寒喜暖（癸冬喜丁）、燥喜润（戊秋喜壬）。→ 与《穷通宝鉴》互为表里，盲派调候之根。
- **刚柔**：善制者引其性情——刚者济柔（庚七月用壬不用癸戊）、柔者济刚（乙八月用丁不用丙甲）。「泄者有生生之妙，克者有成就之功，引者有和悦之情，从者有变化之妙」。
- **从象/化象**：真从（局成势分明）/假从、真化/假化。→ 盲派"从势、化用做功"之源。

## 六、六亲论（盲派六亲规则的祖本，含重大正名）

- **夫妻**：以财为妻。财清身旺妻美、财浊身旺家富；财轻劫重克妻、财重身弱无比劫克妻；身强杀浅财滋杀/印重财得气则妻贤美。
- **子女**：**以食伤为子女**（任氏正名：旧以官为子乃误，官是约束非生养）。身旺无印食伤旺则子多；身旺印重食轻则子少；火炎土燥/金寒水冷/水泛木浮/重叠印绶/财官太旺/满局食伤皆无子。子数：水1火2木3金4土5，当令倍、休囚半。
- **父母**：**以年月官印盛衰断**（任氏正名：旧以财为父印为母"翁女同宗"犯伦理）。年官月印祖上清高；年财月印日主喜印逢伤则破祖。
- **兄弟**：比肩为兄、败财为弟。财官弱比劫显则兄弟强；财轻劫重印制伤则不和。
- **何知章**（盲派"何知歌"之源，逐句）：
  - 富——「财气通门户」（财旺身强、伤官生财流通、暗成财局）。
  - 贵——「官星有理会」（官旺身旺印卫官、财官通达、暗成官局）。
  - 贫——「财神反不真」（九式：财重食多泄过、财轻印旺、财轻劫重、喜财而财合化忌……）。
  - 贱——「官星还不见」。
  - 吉——「喜神为辅弼」；凶——「忌神辗转攻」。
  - 寿——「性定元神厚」（无冲无合无缺无贪、官财伤印俱不绝、五寿征仁静宽德厚）；夭——「气浊神枯了」（印太旺身无着、财杀旺身无依、冲而不和、湿滞燥郁）。
- **女命**：夫星盛衰知贵贱（官太旺以伤为夫、官太微以财为夫）；气静平和则妇道柔顺。任氏斥"二德三奇咸池驿马非关命理"——与江湖派神煞论相左，盲派两者并取（理法从任氏、铁口断从江湖）。

## 七、《滴天髓》→ 盲派 对接表（改了什么名）

| 滴天髓 | 盲派 | 关系 |
|---|---|---|
| 气势、顺悖、进退 | 势、成党、做功方向 | 盲派口语化、可操作化 |
| 用神（不拘十神皆可用） | 功神/废神 | 盲派弃"用神"名、立做功 |
| 通关（静态原局） | 做功（动态岁运激活） | 盲派扩展为运程体系 |
| 衰旺真机·五行颠倒 | 成势、金木形论、势与日主一致 | 盲派的"成势"判级 |
| 寒暖燥湿 | 调候、十干四季喜忌 | 同源（＋穷通宝鉴） |
| 真假神、隐显 | 虚实、换象、反客为主 | 盲派应期核心 |
| 源流、阻节之神 | 找源头归宿、谁挡功 | 盲派读势 |
| 何知章、六亲论 | 何知歌、分科断法 | 盲派直接继承＋正名（食伤为子、官印断父母） |
| 官杀去留、伤官五格 | 官命五式、伤官当财/配印 | 盲派继承 |
| 旺者冲衰衰者拔 | 成势制弱、冲制 | 盲派继承并把"穿"提到第一 |

**一句话**：《滴天髓》给的是"为什么"（理），盲派给的是"怎么断"（技与象）。读盲派必先通《滴天髓》的衰旺真机与顺逆之机；否则只会背口诀不会判势。**两处盲派明确超越/偏离任氏**：①把"穿（害）"从"非关命理"提为头等杀伤；②把神煞（任氏全弃）在铁口直断层大量复活。
