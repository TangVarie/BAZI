## 二、核心判断：知识库从「单轴」走向「双轴」

现知识库以**段氏盲派做功体系**为唯一主干，`01-理法总论` 开宗明义"**不以日主旺衰取用神**"，用「功神/废神」取代「用神/忌神」。

本批 5 份资料中，A/D/E 三本是**古典子平格局/用神派**（即盲派自我标榜所"对着干"的"书房派"），C 是**神煞-禄命法**，B 是**传统六亲法**。它们共享一套与盲派**正交（不同方法论轴）**的内核：

- **取用神**（而非取功神）
- **重旺衰/中和**（而非论势）
- **月令取格 → 格局成败救应**（而非做功效率）
- **向官临财**为贵贱本位（而非做功落点）

因此"融会贯通"的本质不是给盲派打补丁，而是**建立第二条引擎并定义两轴的映射、分工与取舍**。

## 三、两轴映射表（最关键的整合资产）

经四份消化笔记交叉印证，子平/格局派与盲派做功**在"对凶神施加动作"这一层高度同构**，可建立稳定映射：

| 子平/格局派 | 盲派做功 | 关系 |
|-------------|----------|------|
| 官印相生 / 杀印相生（化煞） | **化用** | 一致（"化官无官灾"两派同口径） |
| 食神制杀 / 伤官驾杀 / 杀刃双显 | **制用** | 一致（制要干净=成贼神捕神） |
| 财旺生官 / 财滋弱杀 | **生用** + 官当财 | 半一致 |
| "官杀制不尽当财看 / 财统官" | "官杀制不尽当财看（财统官）" | **逐字相合** |
| 贪财坏印（第一败格）/ 官杀作桥通关 | 财制印得权 vs 被财坏印 / 通关 | 一致 |
| 比劫劫财夺财（逐马最凶） | 比劫与财配置 / 财被劫=穷命 | 一致 |
| 顺逆用神（财官印食顺、杀伤劫刃逆） | 体用 + 制用五大配置 | 一致（逆用≈做功制凶） |
| 月令取主气、客无胜主、取用定式 | 看做功（不取用） | **冲突** |
| 用神=贵物尊神，君不可逆 | 取消用神，功神/废神 | **冲突** |
| 旺衰/中和（身旺任财任官） | 不用旺衰，只论势 | **冲突** |

**结论性工作流（推荐）**：
> **盲派定"做功效率与应期"（要拿到什么、何时应）；子平/格局定"贵气清浊与品级"（这层富贵是清是浊、是文是武）。**
> 即"做功定档次与时机，格局定调与质感"，矛盾处（用神/旺衰/取用）一律回到盲派做功本源，子平结论仅作"传统视角"互参标注。

### 术语冲突警示（整合时必须标注）
**"体用/宾主/势/虚实"在两派下定义不同，不可混用：**
- 子平"体用"=日主为体、六神为用；盲派"体用"=做功语境的体（印禄比劫）与用（财官杀）。
- 子平"宾主"=日为主时为宾的宫位伦理；盲派"宾主"=做功中的主宾力量。
- 子平"虚邀/向实寻虚"=外格邀合；盲派"虚实"=本柱有根无根的状态。
