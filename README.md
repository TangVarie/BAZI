# 盲派八字综合知识库（多流派融会贯通版）

本知识库系统整理自 52 份盲派八字内部资料（约 150 万字），以**段建业（段氏盲派）理法体系为骨架**，融合九大流派的独门技法而成。目标：形成一套「拿到八字即可按图索骥、铁口直断」的完整操作体系。

## 资料来源（已消化的流派）

## 使用原则

1. **理法以段氏为准**：宾主体用做功是读懂八字的根本框架；
2. **直断以口诀为辅**：郝金阳、清娟、江湖口诀用于细节铁口直断与验证时辰；
3. **疑难用替代视角**：日主不做功、格局不明时，换飞宫法找真命主，或用清娟暗引、素水出处论重新立极；
4. **应期多法互参**：禄/原身/遁藏透干/虚实/合冲穿，多条线索指向同一年份才下重断；
5. **矛盾处见 06 篇取舍表**。

> 资料中各派断语均为传统命理学内容，供研究与文化学习使用。
