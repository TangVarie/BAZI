# 盲派八字综合知识库（多流派融会贯通版）

本知识库系统整理自盲派八字内部资料（约 150 万字），以**段建业（段氏盲派）理法体系为骨架**，融合九大流派的独门技法而成。目标：形成一套「拿到八字即可按图索骥、铁口直断」的完整操作体系。

> **演进（2026-06）**：并入古典**子平系**资料后，曾试"六模块加权投票"——按流派投票反而越断越乱（一个流派横跨所有环节）。经盲跑校准与方法论复盘，**定型为"深读收敛主干 ＋ 专门技法库"**：
> - **收敛主干**：一套深读收敛的整合看命法——做功（定得失应期）/格局（定品级清浊）/气数调候（定底色）是**同一盘的不同入口，深读则自洽合一，不投票**；冲突＝读浅了，回去重读。
> - **专门技法库**：飞宫/纳音生克/神煞专断/郝铁口/刘军数目/串宫/三限/星宗等，按"问题/情境"**触发调用**，解决主干答不了的具体问题或给独到解读，不参与主干收敛——这是多技法的魅力，不弃。
> - **元层**：现实脸校验、命例回测、硬断降级、置信分级。
>
> **总入口与全部标准见 [`00-元引擎总纲`](knowledge/00-元引擎总纲.md)；技法遍历与分类见 [`_待整合/技法遍历与配合分析`](knowledge/_待整合/技法遍历与配合分析.md)。** 14–18 等为**知识库/查典**（技法出处），非"投票模块"。

## 使用原则

0. **先看 `00-元引擎总纲`**：它定义多法并断的调度、问题域权重与取舍；下列原则是其内核的口语版。
1. **理法以段氏为准**：宾主体用做功是读懂八字的根本框架，富贵层级与做功落点以此定档；
2. **直断以口诀为辅**：郝金阳、清娟、江湖口诀用于细节铁口直断与验证时辰；
3. **子平系补清浊与温度**：贵气清浊品级用 M2 格局，调候温度健康用 M7 气数，职业性情用 M5 象法；与做功冲突时回做功本源；
4. **疑难用替代视角**：日主不做功、格局不明时，换飞宫法找真命主，或用清娟暗引、素水出处论重新立极；
5. **应期多法互参**：禄/原身/遁藏透干/虚实/合冲穿，多条线索（含子平换格、气数岁运、神煞流年）指向同一年份才下重断；
6. **跨模块共识即铁断**：职业落象四源、宫位三源、调候三源、生死三源同指方下重断；
7. **矛盾处见 06 篇取舍表 + 00 第五~七节**（含术语命名空间，防同名异义污染）。

> 资料中各派断语均为传统命理学内容，供研究与文化学习使用。
